AFTERWORD — XENO 1st ALBUM
専用Webプレイヤー / 全16曲＋ボーナストラック1曲

■ 使い方（パソコン）
1. このZIPファイルを「すべて展開」してフォルダーを取り出す。
2. フォルダー内の index.html をChrome / Edge / Safari等で開く。
3. 「アルバムを再生」を押すと曲順どおり自動連続再生する。

■ スマートフォン向けに配布する場合
このフォルダーを丸ごと静的Webホスティングにアップロードすると、URLからスマホでも再生できます。
ZIPの中の index.html だけを送っても音源は再生されません。必ず audio / covers を含めてください。
Webへの設置後も、スマホのOSやブラウザの制限により、最初の再生開始にはタップ操作が必要です。

■ 機能
・全曲自動連続再生 / 曲を選択して再生 / 一時停止 / 前後曲 / シーク
・シャッフル / リピート（オフ→全曲→1曲） / 音量調整
・16曲の各ジャケット、メインジャケットは元画像を無加工で採用
・ボーナストラックは専用画像が未提供のためメインジャケットを流用
・インターネット接続なしでも、ZIPを展開したフォルダーから再生可能な構成
